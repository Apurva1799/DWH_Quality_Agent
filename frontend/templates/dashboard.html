About

About This Dashboard

A comprehensive overview of the Data Warehouse Quality Agent.

Welcome to DWH Quality Tool

This tool provides real-time monitoring and quality assessment of the data warehouse, focusing on the Gold layer, stored procedures, and metadata management.

Gold Layer Quality

Monitor the health and quality of the Gold database tables. This tab provides:

  • Quality Scores: Overall health indicators for each table (0-100 scale)
  • Issue Detection: Identifies null values, duplicates, and constraint violations
  • Detailed Metrics: Uniqueness, null percentages, and PK/FK presence
  • Score Weights: See how each metric contributes to the overall quality score

Job Status

Track the execution status of data refresh jobs and stored procedures:

  • Latest Execution: Most recent run status for each procedure
  • Execution Time: Duration and timestamp of last run
  • Status Indicators: Success, failure, or in-progress states

Stored Procedures

Analyze the code quality of all stored procedures in the database:

  • Quality Scores: Rule-based assessment of best practices
  • Code Issues: Identifies missing error handling, transaction management, and more
  • AI Analysis: Optional AI-powered code review and suggestions
  • Best Practices Guide: Collapsible table explaining quality parameters

Metadata Layer

Explore the schema and business context of all tables in the data warehouse:

  • Table Cards: Visual overview of each table with key information
  • Column Details: Data types, sample values, and descriptions
  • Business Context: Grain information and related dimensions
  • Filtering: Filter by Fact tables or Dimension tables with pagination

Getting Started

Start by exploring the Gold Layer Quality tab to understand the current state of the data. Use the Job Status tab to monitor refresh operations, and check Stored Procedures for code quality insights. The Metadata Layer provides comprehensive documentation for all the tables.
